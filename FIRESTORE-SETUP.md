# SKOS Cloud на бесплатном Firebase Spark

Используется проект titanium-web-516010-u9. Firebase Authentication принимает почту
и пароль. Правила Firestore дают запись только UID владельца, чтение текущих
и прошлых версий — владельцу и одному утверждённому UID читателя.
Любой другой аккаунт получает отказ, даже если он зарегистрирован в Firebase.

1. В Firebase Console создайте в проекте базу Firestore (Standard, Production mode).
2. В разделе Firestore → Rules опубликуйте файл firestore.rules из тестовой ветки.
   В нём разрешены только служебные коллекции SKOS; другие данные он не раскрывает.
   Если в проекте уже есть посторонние коллекции, сохраните их существующие правила отдельно.
3. Проверьте на тестовой копии вход двумя существующими Firebase-аккаунтами. Владелец
   сохраняет две версии, читатель видит последнюю, может открыть первую, но не может писать.
4. Переключайте основной сайт после теста, имея локальный JSON-бэкап рабочей базы.
   Firestore получает снимки по кнопке «Облако» и не импортирует Google Таблицу автоматически.

Снимок и указатель на последнюю версию записываются одной пакетной операцией.
Сохранённые версии запрещено менять и удалять правилами приложения. Снимки до 8 МиБ
несжатого JSON и до 6 МиБ в сжатом виде укладываются в один пакет. При приближении
к лимиту бесплатного проекта сохраните резервные копии для дальнейшего архивирования.
