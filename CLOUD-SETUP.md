# SKOS Cloud

Вход по электронной почте и паролю обеспечивается Firebase Authentication. Сайт запоминает
сессию в браузере, сервер проверяет Firebase ID-токен и роль по UID при каждом запросе.
Владелец публикует снимки. Читатель получает только текущий опубликованный снимок.
Google Sheets доступна серверу через сервисный аккаунт, а коллеги могут работать без доступа к файлу.

## Настройка в существующем проекте Google Cloud

1. Подключите Firebase к проекту, включите Authentication → Email/Password, зарегистрируйте
   веб-приложение и добавьте домен `merdanyolbarsov-hub.github.io` в Authorized domains.
   Создайте два тестовых аккаунта в Authentication → Users и скопируйте их UID.
2. Создайте сервисный аккаунт для Cloud Run без JSON-ключа. Для проверки отзыва ID-токенов
   выдайте ему Firebase Authentication Viewer. В Google Sheets предоставьте этому сервисному
   аккаунту роль редактора в закрытой тестовой книге. В книге нужен лист `CLOUD_DB`.
3. Разверните каталог `cloud-server` в Cloud Run и назначьте ему этот сервисный аккаунт.
   Вход HTTP доступен браузеру, данные защищены Firebase-токеном и списком разрешённых UID.
   Укажите переменные окружения:
   - `GOOGLE_CLOUD_PROJECT` — ID проекта.
   - `SKOS_SPREADSHEET_ID` — ID тестовой Google Таблицы.
   - `SKOS_INDEX_SHEET_ID` — числовой gid листа CLOUD_DB (может быть 0).
   - `SKOS_OWNER_UID` и `SKOS_VIEWER_UIDS` — UID владельца и список UID читателей через запятую.
4. Внесите HTTPS URL Cloud Run и публичную конфигурацию Firebase Web App в `cloud-config.js`.
   Проверьте вход обоих аккаунтов и отказы для постороннего аккаунта и POST от читателя.
5. На тестовых данных опубликуйте две версии. Проверьте, что читатель видит последнюю, а
   владелец может скачать предыдущую. Для переключения используйте рабочую таблицу только
   после бэкапа, проверки её доступа и проверки восстановления старых данных.

## Версии

Каждый успешный вызов «Облако» создаёт лист `SKOS_V_…` и одним атомарным запросом
обновляет указатель `CLOUD_DB!D1:G1`. Ячейка A1 и ранее сохранённые листы не изменяются.
Скачивание выбранной предыдущей версии доступно владельцу. Google Sheets ограничивает
общий размер книги, поэтому при росте истории понадобится архив.
